# 番茄钟 · 计时

Windows 原生桌面番茄钟 / 计时器。纯 Rust + Win32 + Direct2D，**无 WebView、无 Electron、无 .NET 运行时**，编译产物是单个 exe（约 350 KB），双击即用。

## 技术栈

- **语言/构建**：Rust 2021 + cargo（release 配置 `opt-level="z"`、LTO、strip、`panic=abort`）
- **窗口**：Win32（`windows` crate 0.61），Per-Monitor-V2 DPI，DWM 暗色标题栏 + 圆角
- **渲染**：Direct2D（几何 / 圆环填充）+ DirectWrite（文字与字体回退；图标统一用 `ui/icons.rs` 里的文本字形，避免回退成彩色方框）
- **交互**：立即模式绘制 + 每帧命中列表（绘制时收集 `hit(rect, Action)`，`WM_LBUTTONDOWN` 时取最上层命中并派发 `Action`）
- **文字输入**：编辑框的位置上挂一个真正的系统 EDIT 控件（宿主小窗 + 子控件），中文输入法、组字、候选窗、上屏、光标、选区、剪贴板全交给 Windows；自绘部分只负责摆位置和把文本同步回 `rt.edit`
- **状态**：内存中的 `App` 模型 + JSON 持久化（原子写）
- **系统集成**：`Shell_NotifyIconW` 托盘、`PlaySoundW` 提示音、`ChooseColorW` 取色、`GetOpenFileNameW` 选 wav
- **计时精度**：所有计时都以「截止时刻 + `GetTickCount64`」计算，不累加 tick，睡眠/唤醒后不漂移
- **依赖**：仅 `windows` / `windows-numerics` / `serde` / `serde_json`，全部离线可编译

## 架构总览

一句话：**立即模式（immediate-mode）的 Win32 界面**——每帧重画整屏，控件在绘制时顺手登记 `Action` 命中矩形，鼠标按下时取最上层命中并派发。

```
Action（用户意图：点按钮 / 托盘菜单 / 快捷键）
   │
   ▼
app_actions::apply(host, action, rect)      唯一的业务入口：改 App 状态 + 产出 Effects
   │
   ▼
App（领域模型，JSON 持久化） + Runtime（纯界面态：滚动 / 折叠 / 下拉 / 编辑 / 悬浮窗三态）
   │
   ▼
views::draw(ui, app, rt)                    立即模式绘制，同时收集命中列表 + 记录编辑框位置
   │
   ▼
Direct2D / DirectWrite → 主窗口 HwndRenderTarget ／ 悬浮窗 32bpp DIB → UpdateLayeredWindow
```

- **单线程单 Host**：`thread_local! { HOST: RefCell<Option<Host>> }`，所有窗口过程 / 定时器都经 `with_host` 取同一份状态；要弹模态框或建拆窗口时先记 `rt.pending`，出了借用再在消息循环里执行（避免 RefCell 双借用 + WndProc 重入）。
- **计时**：全部按「截止时刻 + `GetTickCount64`」算，不累加 tick。主窗口定时器 200ms / 1s 自适应；悬浮窗自带 100ms 心跳，不依赖主窗口可见性。
- **文字输入**：编辑框位置挂一个系统 EDIT 控件（宿主小窗 + 子控件 + 会话号协议 `WM_EDIT_CHANGED / COMMIT / CANCEL`），输入法 / 光标 / 选区全归 Windows；自绘部分只摆位置、同步文本。
- **自愈**：`Ui::end()` 里 EndDraw 失败就丢掉渲染目标重建；悬浮窗尺寸变化时重建 DIB 并重新 `BindDC`。

## 体积与内存（本机 144 DPI 实测）

| 指标 | 数值 |
| --- | --- |
| exe 体积 | **348 KB** |
| 专用工作集（Private Working Set） | **17.4 MB**（稳定） |
| 总工作集 | 53 MB（含 Direct2D / DirectWrite / GDI+ 等系统 DLL 的共享页） |
| 线程数 | 35 |
| 磁盘占用 | 无运行时、无 node_modules、无缓存目录 |

对照：Tauri 2 + WebView2 的桌宠方案，Rust 主进程仅 4.7 MB，但 WebView2 子进程会额外常驻约 100 MB——这部分开销来自浏览器内核，与页面复杂度无关。本方案把它整个省掉了。

## 功能

### 计时视图

- 专注 / 休息 模式切换（运行中禁止切换，提示「请先结束或重置当前计时」）
- 活动下拉 + ✏ 自定义活动（回车确认、Esc 取消、点击别处确认；空值忽略，新名称自动加入事件列表）
- 大号计时 `mm:ss`（专注用专注色，休息用短休色）
- 开始 / 暂停 / 继续（暂停态按钮转「暂停色」）、跳过、重置（空闲且 0 秒时禁用）
- 跳过 = 进下一个状态：专注 ↔ 休息；跑着的话先把这一段存进历史（`提前结束`），再切模式
- 今日专注 / 今日休息 统计卡

### 番茄钟

- 专注 / 短休息 / 长休息 三阶段 tab（运行中禁止切换）
- 活动行（同计时视图，可自定义）
- 三种视觉模式：**简洁**（纯数字）、**条形**（数字 + 进度条）、**环形**（圆环进度，从 12 点方向顺时针）——在设置中选择，「隐藏文字」仅对图形模式生效
- 开始 / 暂停 / 继续（暂停态用暂停色）、跳过、重置（空闲且满额时禁用）
- 跳过 = 进下一阶段：专注 → 短休息 → 专注 …（跑满一个循环进长休息）；跑着的话先把这一段记进历史
- 今日专注 / 今日休息 / 当前循环 `x / y` 三张统计卡
- 可折叠「计时方案」卡片（与设置页共用同一张卡片）
- 阶段结束：提示音（可循环）+ 托盘气泡通知；按方案设置可自动开始下一阶段

### 历史

- 过滤：类型（全部 / 专注 / 休息）、事件、日期范围
- 日历弹窗：月份切换、跨月补白、今天高亮、区间选择（两次点击成区间，反向点击自动交换）、清除 / 应用、点击外部关闭
- 批量：全选、已选计数、批量删除
- 统计：专注分钟 / 休息分钟 / 记录数（随过滤联动）
- 记录行：复选框、🍅 / ☕ 圆点、事件名、`类型 · 日期 时间` + `· 提前结束` + `· 番茄钟`、时长 `X分Y秒`
- 空态：没有符合条件的记录

### 设置

**计时方案**（可折叠，与番茄钟视图是同一张卡片）

- 方案下拉、＋ 新建、📕 保存、🗑 删除（至少保留一个）、方案名称输入
- 专注 / 短休 / 长休：事件下拉 + 分钟步进（数字区域点击可直接输入）
- 长休前轮数、提示音（🔔 铃声 / 🔕 叮咚 / 🎵 风铃 / 📁 自定义 + 上传 wav）
- 开关：自动开始专注、自动开始休息、提示音循环

**事件管理**

- 标签列表 + ✕ 删除（至少保留一个；删除时同步清理所有方案对它的引用）
- ＋ 添加事件行内编辑器（添加 / 取消）

**视觉设置**

- 番茄钟设置：简洁 / 条形 / 环形 三张视觉模式卡 + 「隐藏文字（仅图形模式生效）」
- 颜色设置：系统预设 9 套、我的预设（逐个改色 / 应用 / 删除）、自定义颜色（命名 + 7 个取色器 + ＋新建 + 保存当前为预设）、黑暗模式、跟随系统
- 文字设置：字体族下拉、字号 36–80px、字重 200–800（步进 50）、实时预览、隐藏界面文字（保留必要图标）
- 界面设置：无背景界面（默认开，不画外层卡片）、窗口大小 4 档（紧凑 470×580 / 小 505×660 / 标准 545×740 / 大 620×840）、桌面小图标开关

设置界面的文字永远不隐藏（否则开关自己都看不见），其他视图跟随「隐藏界面文字」。

所有改动自动保存。

### 桌面小图标（悬浮窗）

无 WebView、无图片资源的独立小窗，和主窗口共用同一份状态与配色（数字颜色 = 当前阶段色）。

- 透明底、无边框；数字形态跟随「番茄钟设置」的简洁 / 条形 / 环形，三种形态共用同一套版面
- 版面自上而下：活动行 [● 活动 ✎]（严格居中）→ 数字 / 图形 → 图标行 [↻ 刷新][✕ 关闭]〔◷ 计时 / ◎ 番茄钟〕[⚑ 固定][◌ 穿透][↗ 主界面][＋ 回运行 / − 收起] → 控制行 开始（暂停） / 跳过 / 重置
- 三种状态：待机·未点击只显示活动与数字 / 图形；待机·已点击多出图标行（没有 开始 / 结束 / 重置）；运行模式图标行 + 控制行全在
- 切换：点活动 / 数字 / 空白在「待机·未点击 ↔ 待机·已点击」之间切；点 ＋ 进运行模式、点 − 直接收起成待机·未点击；运行模式 15 秒没动静也会自动收起
- 图标行开关：⚑ 固定位置（开着时拖不动）、◌ 点击穿透（用 `WS_EX_TRANSPARENT` 做整窗穿透，不再靠透明像素碰运气；开着时小图标自己点不到，只能从托盘右键菜单或设置里关掉）；开着的时候按钮用阶段色标出来
- 跟随模块：中间两个按钮直接指定小图标跟「计时」还是「番茄钟」；主界面切到这两个视图时也跟着走，切到历史 / 设置时保持不变（不会莫名其妙跳到计时）；哪个模块刚开始跑也会自动切过去
- ↻ 刷新：重挂 100ms 心跳、按当前状态重算尺寸、重设窗口样式并立刻重绘（切模块 / 改设置后小图标没跟上时点一下）
- 拖动：按住任意位置（数字旁边的空白也算，铺了一层 alpha = 1/255 的底让整块矩形都参与命中）都能拖动，位置自动记住（存进 state.json）
- 活动行：点名字展开活动列表直接切换；✎ 就地改名（支持中文输入法）
- 文字输入：改名 / 数字 / 方案名都挂一个真正的系统 EDIT 控件在上面，中文输入法（拼音组字、候选窗、上屏）、光标、选区、Ctrl+A/C/V 全交给 Windows，自己不再解析 WM_IME_*
- 跟随「隐藏界面文字」：开启时数字也不画，只留环形 / 条形
- 托盘右键菜单里也能显示 / 隐藏
- 复用主窗口的 Direct2D / DirectWrite 工厂，只多一块 32bpp 位图和一个离屏渲染目标（专用工作集约 +2 MB）

### 提示音

- 循环提示音有两种结束方式：点系统气泡，或点数字右侧的「结束提示音」按钮；没有提示音时按钮不出现。

### 托盘

- 左键单击 / 双击：显示主窗口
- 右键菜单：显示窗口 / 显示（隐藏）桌面小图标 / 小图标点击穿透 / 开始（暂停）番茄钟 / 跳到下一阶段 / 退出
- 悬停提示：实时显示番茄钟剩余时间或在计时的时长

### 全局

- 提示条（吐司）2.2 秒自动消失
- 时间格式 `mm:ss`，时长格式 `X分Y秒`
- 各视图滚动位置独立记忆

## 数据

- 配置与历史：`%APPDATA%\PomodoroTimer\state.json`（删除即恢复默认）
- 快捷键：无全局热键；程序最小化后仍在托盘运行

## 关键修复与优化

- **悬浮窗画面不再“要重开才更新”**：`Widget::resize` 建好新位图后曾把 DC 原来的 1×1 位图选回去，等于把我们的位图换出 DC，之后 D2D / `UpdateLayeredWindow` 都画不出东西；现在只删旧位图、保留新位图在 DC 里。
- **中文输入**：删掉整套自绘输入法代码（`WM_IME_*` 解析、自画组字串与光标、上屏去重），改用系统 EDIT 控件，任何输入法都兼容。
- **死代码清理**：删掉 20 处编译告警里的全部未使用函数 / 常量 / 结构（`Layout`、`card`、`checkbox_row`、`divider`、`align_text`、`tab_items`、`view_of`、`section_of`、`drop_of`、`day_of_month`、`class_name`、`title_ptr`、`icons::LAYOUT` 等），并清掉输入改造后残留的 `ime_text` / `caret` 状态，现在 `cargo build --release` **零告警**。
